deserved is a tiny, zero-dependency Bun static file server.

Key features

  • Directory listings with file sizes and modification times
  • Live reload via Server-Sent Events (SSE)
  • CSS-only hot-swap for stylesheet changes
  • SPA mode with fallback to index.html
  • Range requests for media files
  • Gzip compression
