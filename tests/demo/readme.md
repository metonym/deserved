# Directory Listing Demo

This directory demonstrates the deserved server's directory listing feature.

## Features shown

- **File sizes**: displayed in human-readable format (B, kB, MB)
- **Modification times**: shown in YYYY-MM-DD HH:mm format
- **Directory markers**: directories display "-" for both size and date
- **Live reload**: changes to files are reflected immediately with `--watch`

## Try it

Navigate to the root to see the directory listing, or explore the subdirectories.
